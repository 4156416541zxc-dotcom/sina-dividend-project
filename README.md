# 比亚迪(002594.SZ) 后复权股价走势分析与可视化

基于 2023-01 至 2026-10 共 922 个交易日的后复权日线数据，完成趋势分析、均线系统、成交量联动与年度收益统计，并通过 TDesign + ECharts 输出交互式可视化页面。

## 数据说明

| 区间 | 来源 | 条数 |
|---|---|---|
| 2023-01-03 ~ 2023-12-29 | 原始 Excel | 242 |
| 2024-01-02 ~ 2026-10-27 | 东方财富公开 API (fqt=2 后复权) | 680 |
| **合计** | | **922** |

字段：日期、开盘、收盘、最高、最低、成交量(手)、成交额(元)、振幅(%)、涨跌幅(%)、涨跌额(元)、换手率(%)。

## 快速开始

```bash
# 1. 重新生成合并数据（可选，data/byd_post_adjusted.csv 已存在）
python analysis/fetch_and_merge.py

# 2. 计算指标并输出统计
python analysis/analyze.py

# 3. 启动可视化页面
cd web
npm install
npm run dev
```

## 分析指标

- 收盘价走势 + MA5 / MA20 / MA60 / MA120 均线
- 成交量与量价配合
- 年度收益率（2023 / 2024 / 2025 / 2026 YTD）
- 月涨跌幅热力分布
- 区间最高/最低/最大回撤

## 技术栈

Python 3 · pandas · Vite · Vue 3 · TDesign Vue Next · ECharts 5
