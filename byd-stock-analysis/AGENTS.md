# AGENTS.md — 比亚迪股票价格走势分析与可视化项目

## 一、项目背景

本项目为教材 P92 页「实战演练：比亚迪股票价格走势分析与可视化」的 AI 辅助实现。

- **分析标的**：比亚迪（002594.SZ）
- **数据区间**：2023-01-03 至 2023-12-29（后复权日线）
- **数据规模**：242 个交易日
- **数据字段**：日期、开盘、收盘、最高、最低、成交量、成交额、振幅、涨跌幅、涨跌额、换手率
- **交付形态**：移动端 H5 静态页面（无需后端服务，浏览器直接打开）

## 二、技术选型约束

| 类别 | 选型 | 说明 |
|------|------|------|
| 页面框架 | 纯 HTML5 + CSS3 + 原生 JavaScript | 静态页面，不引入 Vue/React 等构建工具链 |
| UI 组件库 | TDesign Mobile（CDN 引入） | 腾讯开源移动端设计系统，通过 CDN 直接使用组件样式 |
| 数据可视化 | Apache ECharts 5（CDN 引入） | 支持 K 线图、折线图、柱状图等金融图表 |
| 数据格式 | JSON（本地 data.json） | 由 analyze.py 从 Excel 导出，页面通过 fetch 加载 |
| 适配方案 | viewport 移动端适配 + rem | 设计宽度 375px，适配主流手机屏幕 |
| 图表主题 | 深色金融风 | 背景 #0d1117，涨红跌绿（A股配色） |

## 三、页面结构约束

移动端单页纵向滚动，包含以下模块（自上而下）：

1. **顶部导航栏**：股票名称 + 代码 + 期间标签
2. **行情概览卡片**：最新价、涨跌幅、年度高低点、成交额等核心指标
3. **K 线图模块**：日 K 蜡烛图 + MA5/MA10/MA20/MA60 均线
4. **成交量模块**：成交量柱状图（涨红跌绿）
5. **月度涨跌图**：柱状图展示各月涨跌幅
6. **统计指标卡片**：上涨/下跌天数、日均成交量、最大单日涨跌等
7. **底部说明**：数据来源与免责声明

## 四、数据处理规则

- 后复权数据直接使用，不做二次复权计算
- 均线按收盘价计算：MA5 / MA10 / MA20 / MA60
- 月度统计按自然月聚合，月涨跌幅 = (月末收盘 / 月初开盘 - 1) × 100%
- 涨色：#ef4444（红涨），跌色：#22c55e（绿跌），符合 A 股习惯
