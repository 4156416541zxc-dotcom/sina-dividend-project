## 技术决策摘要

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 图表库 | ECharts 5 | 原生支持 K 线（candlestick）、均线叠加、成交量联动，金融图表生态成熟 |
| UI 组件库 | TDesign Mobile（CDN） | 腾讯开源移动端设计系统，符合作业考核要求；通过 CDN 引入无需构建 |
| 数据内嵌方式 | JSON 内嵌 `<script>` | 避免 file:// 协议下 fetch 跨域限制，双击 HTML 即可打开 |
| 配色方案 | 深色背景 + 涨红跌绿 | 金融终端常见深色风格，A 股红涨绿跌习惯 |
| 均线选择 | MA5/10/20/60 | 短期+中期均线组合，覆盖常用技术分析周期 |

## 关键数据结论

- 比亚迪 2023 年后复权收盘价 200.40 元，较年初下跌 22.22%
- 年内高点 307.38 元出现在 2 月初，低点 185.25 元出现在 12 月下旬
- 全年下跌天数（140 天）多于上涨天数（102 天），整体呈震荡下行趋势
- 总成交额约 6866.82 亿元，日均成交额 28.38 亿元
- 最大单日涨幅 +6.46%（2023-02-01），最大单日跌幅 -5.18%（2023-11-24）
