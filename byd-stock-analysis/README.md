# 比亚迪股票价格走势分析与可视化

基于 2023 年后复权日线数据的移动端 H5 可视化页面。

## 快速开始

直接用浏览器打开 `index.html` 即可查看效果（需联网加载 CDN 资源）。

或启动本地服务：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 功能模块

- 行情概览：年度开盘/收盘、最高/最低、涨跌幅、成交额
- K 线图：日 K 蜡烛图叠加 MA5/MA10/MA20/MA60 均线
- 成交量：涨红跌绿柱状图
- 月度涨跌：各月涨跌幅柱状图
- 统计面板：涨跌天数、日均量、最大单日涨跌

## 技术栈

- TDesign Mobile（UI 组件）
- Apache ECharts 5（图表）
- 纯静态 HTML/CSS/JS

## 数据来源

比亚迪（002594.SZ）后复权历史行情数据，2023 年全年共 242 个交易日。
